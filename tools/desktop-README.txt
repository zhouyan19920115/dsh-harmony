DSH Harmony · 桌面端
=====================

这是手机 App 里带着的「电脑那一份」—— 一个 zip, 265 KB, 里面有 bridge\ 和 relay\ 的源码。

怎么用
------
1. 解压(得到一个「DSH-Harmony-桌面端」文件夹 ✓)
2. 双击「双击我-开始.cmd」✓
3. 窗口闪一下就自己关了 —— 桌面端**已经在后台跑着**, 没有窗口, 关掉它也不会停 ✓
4. 手机上打开 App -> 连接页 -> 点「自动探测」-> 选中这台电脑 -> 自动配对 ✓

(想看地址 / 令牌 / 二维码? 它们在 logs\bridge-daemon.log 里 ✓
 想让它开机就自动跑? 见下面的「注册成服务」✓)

后台运行 / 注册成服务
----------------------
这个桌面端就是一个**后台服务**, 双击只是把它拉起来:

  双击我-开始.cmd              起服务(后台, 没有窗口), 窗口自己关掉
  双击我-开始.cmd --install    顺便注册成「开机自启的服务」(登录时自动在后台起来)
  双击我-开始.cmd --uninstall  取消开机自启
  双击我-开始.cmd --stop       停掉服务
  双击我-开始.cmd --status     看服务在不在跑
  双击我-开始.cmd --foreground 想看实时输出(前台窗口, 关掉窗口 = 停掉服务)

--install 用的是当前用户的 Run 注册表键, **不需要管理员权限** ✓
它登录时由 wscript 拉起来, 一样没有任何窗口 ✓

要不要装 Node.js?
----------------
要 Node.js 22 或更高版本(Node.js 20 不够 —— 里面用了 zstd)。

**没有也没关系 ✓**: 启动脚本会自己去下一个 LTS 的 zip 版装到本文件夹的 runtime\ 里
(不用管理员权限, 不用改 PATH, 不用 npm install ✓)。第一次大概要等一会儿。

手动填地址
----------
不想用「自动探测」也行: 地址是电脑上打印的 http://<电脑IP>:8787, 令牌是同一屏打印的那串。

那个二维码是干嘛的?
-----------------
把手机相机对准它(或用 App 里的扫码), 就直接连上这台电脑了 —— 里面装的是
dsh-harmony://connect?host=...&port=...&token=..., 不用手输那 64 位令牌 ✓
(它只在这台电脑的局域网地址上有效, 换网络就不对了 —— 那就手输地址。)

手机连不上?
------------
多半是防火墙挡住了入站(源码版是 node.exe, 单文件版是 dsh-harmony-bridge.exe)。以管理员身份运行:
  netsh advfirewall firewall add rule name="DSH Harmony Bridge" dir=in action=allow protocol=TCP localport=8787 profile=private

开机自启
--------
想让桌面端开机就在跑:
  双击我-开始.cmd --install
(注册成当前用户的开机自启服务 ✓, 登录时在后台起来, 没有窗口 ✓, 不需要管理员权限 ✓)
取消: 双击我-开始.cmd --uninstall

(还有一个走计划任务的老办法, 需要管理员权限:
   powershell -ExecutionPolicy Bypass -File install-desktop.ps1 -InstallStartup
 一般用不上, --install 就够了 ✓)

要离开 WiFi 也能连(远程)
------------------------
这个项目自带一个**公共中继**(开发者的), 所以新电脑装上就能用远程 —— **你什么都不用配**。
启动脚本已经把它接上了: 手机上点「切到远程」就行 ✓
(桥接第一次启动时会自己去中继登记, 拿到这台电脑专属的凭据, 存在本机 —— 包里不含任何凭据 ✓)

要换成自己的中继:
  双击我-开始.cmd --relay wss://<你的中继地址>/bridge
(中继要公网可达, 而且要有 wss:// 的证书。包里的启动脚本里有一行 PUBLIC_RELAY,
 就是内置的那个公共中继 —— 想永久换掉就改那一行。具体怎么弄, 可以联系开发者 ✓)

更多说明见手机 App 的「设置 -> 关于」, 以及项目仓库里的 docs/QUICKSTART.md。
