# 方案对比: 我们 vs 开源项目 vs 官方产品

> 调研时间 2026-10-22。对比对象: [Happy Coder](https://github.com/slopus/happy)、
> [VibeTunnel](https://github.com/amantus-ai/vibetunnel)、
> [Remodex](https://github.com/emanuele-web04/remodex)、
> [Termopus](https://github.com/Termopus/termopus), 以及 MiniMax Code / TRAE / Claude Code RC
> 这类官方(闭源)产品。
>
> 详细的源码级调研见 [`RESEARCH-mobile-agent-clients.md`](RESEARCH-mobile-agent-clients.md)。

## 1. 一句话结论

**别人做的是"某个 agent 的手机遥控器", 我们做的是"桌面端 DSH 的鸿蒙延伸"。**

别人要把 agent 放到云上、或者把 Codex/Claude Code 搬到一个能远程驱动的运行时里;
我们不新建任何 agent —— 手机看到的就是你正在用的那个桌面端 DSH: 同一份会话、
同一份工具调用、同一条用量统计、同一套界面层级。

## 2. 技术路线

| | 我们 (DSHsync) | Happy Coder | VibeTunnel | Remodex | Termopus | 官方(MiniMax/TRAE) |
|---|---|---|---|---|---|---|
| 手机端平台 | **HarmonyOS / ArkTS** | iOS / Android / Web | 无(浏览器) | iOS / Android | iOS / Android | iOS / Android |
| 驱动的是什么 | **你电脑上的 DSH** | 自己的云端 agent | 一个终端 | Codex | 自己的 agent | 自己的云端 agent |
| 传输 | 局域网直连 **或** 自建云中继 | 托管中继 | 自建中继(WebSocket) | 自建中继 | Cloudflare Durable Object | 官方托管 |
| 出网方式 | 桌面端**主动外拨** | 桌面端外拨 | 桌面端外拨 | 桌面端外拨 | 桌面端外拨 | 桌面端外拨 |
| 账号模型 | 账号 = 共享密钥 + 设备清单 | 客户端持有的 32 字节主密钥 | SSH / PAM / Tailscale | 扫码信任 | mTLS 设备证书 | 官方账号 |
| 端到端加密 | **无** | **有**(TweetNaCl, 每会话密钥) | TLS | TLS + 设备绑定 | mTLS + 硬件密钥 | 有 |
| 中继能看到明文 | 是 | **否** | 是 | 是 | 是 | 否 |
| 服务端可自建 | **是**(两个零依赖 Node 进程) | 服务端源码闭源 | 是 | 是 | 是 | 否 |
| 界面 | **与桌面端 DSH 同一套信息层级与配色** | 自成一套 | 终端流 | 自成一套 | 工具卡片 | 各自独立 |
| 推送 | 未实现(需华为 Push Kit) | 有 | Web Push(VAPID) | 有 | 有 | 有 |

### 我们的链路

```
手机(ArkTS)  ──http/ws──►  云中继(可选, 哑字节管道)  ◄──ws(桌面主动外拨)──  bridge  ──rpc/ws──►  DSH
```

三个设计决定:

1. **不改 DSH。** bridge 是一个外部进程, 通过 DSH 自己的 HTTP/WS 接口读写会话。
   所以你升级 DSH 不会把手机端一起弄坏。
2. **中继是哑管道。** 它不认识业务协议, 只按字节转发, 授权在最后一跳(bridge)判定。
   中继被攻破也拿不到你的会话内容 —— 但**能看见明文**(因为没有 E2E)。
3. **桌面端只外拨。** 不需要公网 IP、不需要端口映射、不需要在家装 VPN。
   纯血鸿蒙装不了 Tailscale/ZeroTier 的 Android APK, 云中继是唯一干净的远程方案。

## 3. 成本

| | 我们 | Happy Coder | VibeTunnel | 官方产品 |
|---|---|---|---|---|
| 手机端 | 一次开发, MIT, 永久免费 | 免费用官方服务 | 免费 | 免费 / 订阅 |
| 服务端 | **自建: 一台 1 核 VPS 即可**(中继常驻内存 < 60 MB) | 官方托管(免费额度) | 自建(一台小机器) | 官方托管 |
| 域名 + TLS | 约 ¥30–60/年(Caddy 自动签证书) | 不需要 | 需要 | 不需要 |
| **合计** | **≈ ¥50/年, 或者 0 元(纯局域网)** | 0 | ≈ ¥50/年 | 0 / 订阅费 |
| 商业使用 | MIT, 随便商用 | MIT(但服务端闭源) | MIT | 受服务条款约束 |

**我们省掉了什么**: 不用付任何人的月费, 不用把源码交给第三方, 不用等对方加鸿蒙支持。
**我们多花什么**: 服务器要自己运维(但中继零依赖, `node relay/src/cli.js` 就能跑)。

**我们弱的地方**: 加密、推送、文件、审批、多人 —— 这些是成熟商业产品用几年时间补齐的。

## 5. 优劣势

### 我们的优势

1. **界面一致性是复刻出来的, 不是想象出来的。** 配色是从桌面端界面直接采样的
   (`#151517` 底 / `#1B1B1C` 侧栏 / `#2C2C2E` 浮层 / `#7AAFFF` 强调蓝), 角色色也纠正过:
   桌面端工具是琥珀 `#DD8629`、助手是紫 `#9474BC`。
2. **零依赖, 可审计。** bridge 和 relay 都是纯 Node 内置模块, 没有一个第三方包。
   `bridge/` + `relay/` 一共几千行, 你可以读完再决定用不用。
3. **不用托管服务。** 你的会话、你的模型密钥、你的电脑, 全程不经过别人的服务器。
4. **鸿蒙是原生 ArkUI**, 不是套壳 WebView —— 深色主题、系统字体、折叠屏/平板适配都是真的。
5. **不新建 agent。** 你桌面上正在跑的那个 DSH 就是被驱动的那个, 上下文、权限、记忆全是现成的。

### 我们的劣势

1. **没有 E2E 加密。** 自建中继能看见明文。Happy Coder 用 TweetNaCl + 每会话密钥解决了这件事,
   我们的账号层只是"共享密钥 + 设备清单", 不是完整的账号系统。
2. **没有推送。** 纯血鸿蒙没有 GCM, 只能用华为 Push Kit, 这需要上架/接入华为开发者服务。
3. **功能面窄。** 文件传输、远程审批、多模态、多人协同都没有。
4. **要自己运维一台 VPS**(如果想远程用)。
5. **生态不成熟。** 官方产品有团队在迭代, 我们只有代码。

### 选型建议

- 想要**和桌面端长得一模一样、用的是同一个 agent**、愿意自己搭一台小机器 → **我们**。
- 想要**开箱即用、有推送、端到端加密** → Happy Coder(但没有鸿蒙, 也没有你的 DSH)。
- 想要**在任意终端/SSH 里驱动远程机器** → VibeTunnel。
- 想要**云端 agent + 远程审批** → 官方产品。

两者不冲突: 官方产品用的是**云端 agent**, 我们用的是**你自己机器上的 DSH**。
