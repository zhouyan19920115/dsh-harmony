# QUICKSTART —— 三步让手机遥控你电脑上的 DSH

## 这是什么

**把手机变成你电脑上 DSH 的遥控器** —— 在手机上看会话、给 agent 下指令, 真正干活的还是你电脑上的那个进程。

写给「不是这个项目作者」的你。整件事的哲学只有一句:

> **桌面端必须跑这份代码, 这是设计如此 —— 手机只是遥控器。**
> 代码、终端、模型密钥都不离开你的电脑; 手机上看到的每一行字, 都是电脑上的 agent 真的在干。

---

## 三步装完即用

### ① 把 App 装到手机上

- 正式发布后从 **Releases** 下载 HAP, 装到手机上 ✓
- 现在就想试: 用 DevEco Studio 打开 `harmony/` 目录直接 Run 到真机 ✓, 或者用命令行装 ✓:
  ```powershell
  hdc install harmony\entry\build\default\outputs\default\entry-default-signed.hap
  ```
  (真机只认**签过名**的 `entry-default-signed.hap` ✓; `entry-default-unsigned.hap` 只给模拟器用 ✓)

### ② 把「桌面端包」发到电脑上, 双击一下就跑

App 里的 **「把桌面端发到电脑」** 按钮会把一个 zip 发到你的电脑(三条路任选: 电脑浏览器直接下载 ✓ / 存到手机再分享 ✓ / 在文件管理里定位后分享 ✓)。

电脑上把 zip 解压, 长这样:

```
DSH-Harmony-桌面端\
├─ 双击我-开始.cmd          ← 双击这个 ✓
├─ dsh-harmony-bridge.exe   ← 桥接本体(自带 Node.js 运行时 ✓)
├─ dsh-harmony-relay.exe    ← 云中继(只有远程访问才用得上 ✓)
├─ install-desktop.ps1      ← 装防火墙规则 / 注册开机自启 ✓
└─ README.txt
```

> ### 🖥️ 电脑上**不用装 Node.js**
> `双击我-开始.cmd` 用的是 `dsh-harmony-bridge.exe`, 那个 exe **自带 Node.js 运行时** ✓。
> 不用装 Node ✓、不用装 npm ✓、不用改 PATH ✓ —— 解压完双击就能跑 ✓。

双击之后弹出的窗口里会有:

```
  局域网地址 : http://<你的电脑IP>:8787
  访问令牌   : <一串随机字符>
  配对码     : <六位数字>        (60 秒一换)
```

> 这个窗口**别关** —— 关掉 = 停掉桌面端服务 ✓。

### ③ 手机上点「自动探测」→ 选中电脑 → 「连接」

1. 打开 App → **连接页** → 右上角点 **「自动探测」** ✓
   - 手机扫本机网段, 电脑上跑着的桥接服务应答 ✓
   - **没装这套东西的电脑根本不响应** ✓ → 所以扫到的就是你要的那台 ✓(局域网里有多少台电脑都不要紧 ✓)
2. 弹出的 **「附近的桌面端」** 列表里选中你的电脑(比如「我的台式机」✓) → 点 **「连接」** ✓
3. 手机用窗口里那个**一次性配对码**自动换令牌 —— **全程不用手输令牌** ✓
   (配对码只活 60 秒 ✓; 过期了就再点一次「自动探测」✓)

连上之后:

- 左边是**会话树**: 工作区 → 对话 → 点开对话后, 它的话题/子任务缩进出现在后面 ✓(和桌面端一模一样 ✓)
- 点一个会话 → 右边是完整对话 ✓
- 底部输入区: `+` 号(指令 / 技能 / 文件 ✓)、权限胶囊 ✓、模型选择 ✓、蓝色发送键 ✓
- 上方绿色条是**排队中的任务** ✓, 可以展开、编辑、插队、删除 ✓
- 右上角红色角标 = 桌面端正在跑 + 排队的数量 ✓; 桌面端一有动静, 手机会收到一条**系统推送** ✓
- 大屏(三折叠 / 平板展开)自动变**双栏**: 左列表 + 右详情 ✓

## 第 4 步 · 出门了怎么用(切到远程)

手机离开家里的 WiFi 也能用, **全程不用手填任何东西**:

1. **电脑上**改用带中继的方式启动 ✓
   - 单文件版: 双击 `双击我-开始.cmd` 之后按提示加上 `--with-relay`(或直接用包里带中继的启动项 ✓)
   - 源码版: `tools\start-desktop.cmd --with-relay` ✓
   - 它会顺手把**云中继**也拉起来 ✓(中继是架在公网上的那台中转机, 桌面端主动外拨, 不用在电脑上开端口 ✓)
2. **手机上**点 **「切到远程(经云中继)」** ✓
   - 电脑把**中继地址和令牌**交给手机 ✓, 手机**自动切换并重连** ✓ —— 不用来回改地址 ✓
   - 令牌依旧**可见、可复制** ✓
3. 之后手机走 4G / 5G 也照样能看会话、下指令 ✓

> 远程这条路的安全边界见下面的「安全上要知道的几件事」✓。

## 常见问题

| 现象 | 多半是 |
|---|---|
| **搜不到电脑** | ① 手机和电脑**不在同一个 WiFi** ✓ ② 路由器开了 **AP 隔离**(手机和电脑互相看不见 ✓) ③ **Windows 防火墙**挡了入站 ✓ —— 管理员身份运行: `netsh advfirewall firewall add rule name="DSH Harmony Bridge" dir=in action=allow protocol=TCP localport=8787 profile=private` ✓ |
| **切远程连不上** | 先看**电脑上的那个窗口**有没有报错 ✓ —— 中继没起来、账号没配好、桌面端被防火墙挡住, 都在那个窗口里写着 ✓; 修好之后再点一次「切到远程」✓ |
| **手机提示没权限 / 收不到通知** | 去手机 **设置 → 应用 → DSHsync → 通知**里把通知打开 ✓(Android 还要允许后台运行 ✓) |
| 提示"桌面端离线" | 电脑上的 DSH 没开, 或者桥接没自动找到端口(用 `--dsh-url http://127.0.0.1:<端口>` 手动指定 ✓) |
| 端口被占用 | `tools\start-desktop.cmd --port 8899` ✓ |
| 点了没反应 | 桌面端正忙(会话列表可能要几十秒 ✓), 桥接会先返回缓存 ✓ |
| 想让第二台手机也用 | App 装上后照第 ③ 步再自动发现一次 ✓; 手机会登记到同一个账号下 ✓, 桌面端「设备」页能看到 ✓ |
| 双击 exe 闪一下就没了 | 在 exe 所在的目录按住 Shift 右键 →「在此处打开 PowerShell」→ 跑 `.\dsh-harmony-bridge.exe` ✓, 就能看到它打印的地址和令牌 ✓ |

## 安全上要知道的几件事

- 桥接服务**只在本机或局域网**提供窄接口(会话 / 消息 / 队列 / 指令 ✓), 它**不等于**把 DSH 的整个网页界面暴露出去 ✓
- 令牌 = 你电脑的遥控器权限, **别贴到聊天窗口** ✓; 配对码 60 秒一换 ✓
- 云中继是**字节管道** ✓, 自己架的才可信 ✓; 用公网中继时请走 **https/wss** ✓
- 桥接进程会读取 DSH 的本地凭据(`~/.dsh/.credentials.yaml` ✓)来代替你操作 DSH ✓ —— 所以它等于持有你电脑的执行权 ✓, 别在不认识的电脑上跑 ✓

## 附:自己跑源码(给开发者)

| | 源码包 | 单文件版 |
|---|---|---|
| 压缩包 | `dsh-harmony-desktop.zip`(~174 KB ✓) | `dsh-harmony-desktop-exe.zip`(~41 MB ✓) |
| 里面有什么 | `bridge\` + `relay\` + 启动脚本 | 两个 exe + 启动脚本 + README ✓ |
| 电脑上要装什么 | **Node.js 20+** ✓ | **什么都不用装** ✓ |
| 怎么启动 | 双击 `tools\start-desktop.cmd` | 双击 **`双击我-开始.cmd`** ✓ |
| 云中继(`--with-relay`) | ✓ | ✓(中继也有 exe ✓) |

源码路线的三步:

1. 装 **Node.js 20+**(https://nodejs.org ✓, 装完开个新的命令行窗口 `node -v` 能出版本号就行 ✓)
2. 把这个仓库复制到电脑上
3. 双击 **`tools\start-desktop.cmd`** ✓ —— 它会检查 Node、检查端口、拉起桥接服务 ✓, **自动找到你电脑上正在跑的 DSH 的端口** ✓(桌面端每次启动端口会变 ✓, 不用你填 ✓)

> 单文件版只能跑在 **Windows x64** 上 ✓。
> 想自己重新打一个: `npm i -g @yao-pkg/pkg` 然后 `tools\build-desktop-exe.ps1` ✓。

更完整的路(要配账号、端口、账号令牌、日志): `powershell -ExecutionPolicy Bypass -File tools\install-desktop.ps1 -?` ✓
