DSH Harmony · 桌面端
=====================

这是手机 App 里带着的「电脑那一份」。

怎么用
------
1. 解压(得到一个「DSH-Harmony-桌面端」文件夹 ✓)
2. 双击「双击我-开始.cmd」✓
3. 窗口里会打印: 局域网地址 / 访问令牌 / 配对码 ✓
4. 手机上打开 App -> 连接页 -> 点「自动探测」-> 选中这台电脑 -> 自动配对 ✓
5. 要离开 WiFi 也能连: 用「双击我-开始.cmd --with-relay」✓, 然后在手机上点「切到远程」✓

(这个窗口别关 —— 关掉 = 停掉桌面端服务 ✓)

两种包, 你要哪个?
----------------
★ 单文件版(推荐 ✓): 里面有 dsh-harmony-bridge.exe
  这台电脑上**什么都不用装** ✓ —— 不用装 Node.js ✓, 不用装 npm ✓, 不用改 PATH ✓。
  解压双击就能跑 ✓。解压后大约占 110 MB。

  小包(174 KB ✓): 里面是 bridge\ 和 relay\ 源码
  这种需要电脑上有 **Node.js 20+** ✓(装 Node 就行, 不用 npm install ✓)。
  好处是体积小, 而且任何装了 Node 的系统都能跑 ✓。

  怎么分: 手机 App 的「发送到电脑」里会有两个包, 选「单文件版」那个 ✓
  —— 除非你的电脑上已经装了 Node.js, 那小包也完全能用 ✓。

手动填地址
----------
想手动填也行: 地址是电脑上打印的 http://<电脑IP>:8787, 令牌是同一屏打印的那串。

开机自启
--------
想让桥接开机就在跑:
  powershell -ExecutionPolicy Bypass -File install-desktop.ps1 -InstallStartup
(它会注册一个计划任务 ✓, 用后台模式跑 ✓, 日志在 logs\ 里 ✓)

更详细的说明在 docs/QUICKSTART.md 里(手机 App 的「设置 -> 关于」里也有)。
